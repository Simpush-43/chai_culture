## 🏛️ Project Overview
This "Coming Soon" landing page was developed as a technical assessment for **Chai Culture**. The objective was to translate a "Royal, Elegant, and Warm" brand identity into a high-performance, mobile-responsive digital experience.



## ✨ Key Features
* **Royal Aesthetic:** Deep espresso and metallic gold palette (#D4AF37) designed for high-end brand positioning.
* **Micro-Interactions:** Staggered entry animations and spring-physics success states powered by **Framer Motion**.
* **Mobile-First Engineering:** Fluid typography and adaptive flex-containers ensuring zero distortion on small-screen devices.
* **Lead Capture System:** Functional state-managed email signup with a seamless transition to a "Reserved" status.

## 🛠️ Tech Stack
* **React.js** - Component-based architecture.
* **Tailwind CSS** - Utility-first styling for precise responsive control.
* **Framer Motion** - High-end UI animations.
* **Lucide React / React Icons** - Optimized SVG iconography.

## 🎨 Design Choices (Evaluation Criteria)
1.  **Brand Fit:** Used a Serif-heavy typographic hierarchy to mirror the brand's royal heritage, balanced with a minimalist layout to maintain a "Premium" feel.
2.  **Responsiveness:** Implemented "Progressive Disclosure" on the Navbar, shortening text for small viewports to prevent collision with the logo.
3.  **Creativity:** Integrated a "Live Pulse" indicator on the 'Launching Soon' badge to create a sense of real-time brand activity.
